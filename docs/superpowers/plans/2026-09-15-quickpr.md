# quickPR Implementation Plan

> Execute inline in the authorized workspace; the directory is new and has no Git checkout to isolate. User has already authorized implementation.

**Goal:** Deliver a runnable cross-platform interactive GitHub file uploader and repository browser.

**Architecture:** Standard-library Python package. Separate local path planning, GitHub transport/tree access, atomic publishing, and terminal interaction. Existing remote tree is the base of every update.

**Tech Stack:** Python 3.9+, urllib, argparse, unittest; setuptools for optional installation.

**Spec:** `docs/design.md`

## Global Constraints

macOS and Windows; no runtime third-party dependencies; preserve unselected remote files; one commit per batch; no credential persistence; no live remote writes during development without a specified destination.

## Tasks

- [x] Local planning: `quickpr/files.py`, `quickpr/errors.py`; tests in `tests/test_files.py`. Verified path mapping, hashing, ignores, frozen bytes, unsafe paths, size limits, remote collisions, modes and sensitive files.
- [x] GitHub and publishing: `quickpr/github.py`, `quickpr/upload.py`; tests in `tests/test_github.py`, `tests/test_upload.py` and real local Git object integration in `tests/test_git_integration.py`. Verified request contracts, lazy directory reads, base tree preservation, one commit, concurrent changes, non-forced updates, response recovery and new branches.
- [x] Terminal product: `quickpr/cli.py`, package entry points, startup scripts and `pyproject.toml`; full interactive flow and command tests in `tests/test_cli.py`.
- [x] Delivery: Chinese README and cross-platform CI configuration supplied; 54 automated tests passed on macOS, syntax compilation and source/installed command smoke tests passed. Public GitHub read-only query succeeded. Windows and live remote write verification limits recorded in `docs/verification.md`.

Each testable task follows failing tests → implementation → passing tests. Update this checklist as tasks complete. No external publication is part of this plan.
